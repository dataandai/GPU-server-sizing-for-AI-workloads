Basics and model source
Hardware and software stack options come from the built-in catalog. The model side is dynamic: built-in, Hugging Face, or manual inline configuration.
For Hungarian target language, the builder applies a conservative token uplift because the same meaning is often expressed with more tokens.
Example: meta-llama/Llama-3.1-70B-Instruct or mistralai/Mixtral-8x22B-Instruct-v0.1
